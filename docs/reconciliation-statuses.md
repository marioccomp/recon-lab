## VALUE MISMATCH

It means the operation exists on both sources, but each amount is different

Example:

internal amount = 1000.00
external amount = 1500.00

## STATUS MISMATCH

It means that the operation exists in both sources, but their statuses are not equal

Example

internal status = "PENDING"
external status = "SETTLED"

## ONLY INTERNAL

It means the operation exists only in the internal source.

## ONLY EXTERNAL

It means the operation exists only in the external source.

## DUPLICATED_INTERNAL

It means the operation is duplicated in the internal source

## DUPLICATED_EXTERNAL

It means the operation is duplicated in the external source
